Política de privacidad de CamaraServer

Última actualización: 12 de septiembre de 2026

1. Información que podemos procesar

CamaraServer puede procesar la información necesaria para ejecutar las solicitudes realizadas por los usuarios, como consultas, URLs o datos técnicos necesarios para proporcionar una función.

2. Uso de la información

La información se utiliza para proporcionar, mantener, proteger y mejorar las funciones del servicio, así como para detectar errores o usos indebidos.

3. Servicios de terceros

Algunas funciones de CamaraServer pueden utilizar APIs y servicios de terceros. Cuando una función requiere un servicio externo, los datos necesarios para realizar esa solicitud pueden ser procesados por dicho proveedor de acuerdo con sus propias políticas.

4. Pinterest

CamaraServer puede utilizar servicios de Pinterest mediante su API para proporcionar determinadas funciones relacionadas con contenido de Pinterest. El uso de los servicios de Pinterest también está sujeto a las políticas y términos de Pinterest.

5. Conservación de datos

Los datos no se conservarán durante más tiempo del necesario para prestar las funciones correspondientes. Los registros técnicos podrán conservarse cuando sean necesarios para seguridad, diagnóstico y funcionamiento del servicio.

6. Seguridad

CamaraServer aplica medidas razonables para proteger la información procesada por el servicio. Sin embargo, ningún sistema conectado a Internet puede garantizar una seguridad absoluta.

7. Cambios en esta política

Esta política puede actualizarse cuando cambien las funciones del proyecto, los servicios utilizados o los requisitos aplicables. La fecha de actualización aparecerá al principio de esta página.

8. Contacto

Para consultas relacionadas con privacidad, utiliza el medio de contacto proporcionado por el responsable de CamaraServer.
